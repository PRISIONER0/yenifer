PRISIONER0

Plataforma web orientada a la distribución de novelas visuales traducidas al español y a la organización de contenido digital para PC y Android.

HTML CSS JavaScript SEO Google Analytics QA

Contexto del proyecto

PRISIONER0 surge como una plataforma independiente para centralizar la publicación y distribución de novelas visuales traducidas al español. El sitio funciona como punto de acceso para los diferentes títulos disponibles, organizando la información de cada proyecto y facilitando el acceso a sus versiones para PC y Android.

El proyecto combina desarrollo web, organización de contenido, optimización para buscadores, analítica y revisión funcional en un entorno construido y mantenido de forma independiente.

Participación en el proyecto

La participación se centró en el trabajo sobre la estructura y funcionamiento de la plataforma, colaborando en tareas relacionadas con HTML, CSS y JavaScript, análisis funcional, documentación, SEO, analítica y pruebas.

El trabajo implicó revisar el comportamiento de las distintas secciones del sitio, analizar la navegación y verificar que los componentes funcionaran correctamente después de incorporar cambios o nuevas funcionalidades.

Desarrollo web

Se trabajó sobre una estructura web basada en HTML, CSS y JavaScript, organizando las diferentes secciones de la plataforma y los componentes utilizados para presentar la información de cada título.

JavaScript se utilizó para incorporar y controlar comportamientos dinámicos de la interfaz, mientras que HTML y CSS permitieron estructurar y presentar el contenido manteniendo una experiencia visual coherente en las diferentes páginas.

Organización del contenido

Una parte del trabajo consistió en organizar la información de los proyectos publicados para que cada título pudiera contar con sus propios datos, descripción, características y opciones de acceso.

Esta organización permite mantener una estructura uniforme en el catálogo y facilita la incorporación de nuevos contenidos sin tener que reconstruir manualmente toda la interfaz.

Mejora visual y experiencia

Como parte del análisis de la plataforma, se propuso una mejora en la presentación visual de la página principal, especialmente en el área Hero, con el objetivo de generar un primer impacto más claro y atractivo para los visitantes.

La propuesta buscó mejorar la jerarquía visual, hacer más visible la identidad del proyecto y facilitar la comprensión del contenido desde el primer momento de navegación.

ANTES
DESPUÉS

SEO

Se trabajó sobre distintos elementos de optimización para motores de búsqueda, incluyendo estructura HTML, títulos, descripciones y organización del contenido, buscando mejorar la forma en que el sitio puede ser interpretado e indexado por los buscadores.

Analítica

También se incorporó Google Analytics para obtener información sobre el tráfico y el comportamiento de los usuarios dentro de la plataforma.

La utilización de analítica permite disponer de información para evaluar el funcionamiento del sitio y observar qué secciones y contenidos reciben mayor interacción.

Pruebas y control de calidad

Antes y después de realizar modificaciones se llevaron a cabo pruebas funcionales sobre la navegación, enlaces, componentes de interfaz y diferentes comportamientos implementados mediante JavaScript.

El proceso de revisión permitió detectar errores, comprobar cambios y verificar que las nuevas implementaciones no afectaran negativamente a otras partes de la plataforma.

Documentación y análisis funcional

El trabajo también incluyó análisis de funcionalidades y documentación de diferentes componentes del proyecto, facilitando la comprensión de cómo se relacionan las distintas partes del sitio y qué función cumple cada una.
