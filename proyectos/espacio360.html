PROYECTO PROPIO

SPACE 360

Ecosistema educativo digital enfocado en Cloud, Inteligencia Artificial y automatización, desarrollado para la distribución de contenidos, captación de leads e integración de diferentes servicios tecnológicos.

HTML CSS JavaScript n8n Google Cloud OAuth2 APIs

Contexto del proyecto

SPACE 360 fue desarrollado como un proyecto propio orientado a la creación de un ecosistema digital educativo relacionado con tecnología, Cloud, Inteligencia Artificial y automatización.

La propuesta combina una landing page, contenidos educativos, captación de usuarios e integración de diferentes servicios para construir una experiencia digital completa.

Objetivo del proyecto

El objetivo principal fue desarrollar una plataforma capaz de presentar de manera clara un roadmap educativo para personas que desean comenzar a aprender Cloud, IA y automatización desde cero.

Además de presentar el contenido, el proyecto fue diseñado para permitir la captación de usuarios interesados y facilitar la distribución del material educativo.

Desarrollo de la landing

La landing fue desarrollada utilizando HTML, CSS y JavaScript, construyendo una interfaz visual orientada a presentar la propuesta de SPACE 360 de forma clara y accesible.

La página incorpora diferentes secciones para presentar el roadmap, módulos de aprendizaje, herramientas, perfiles de usuarios y recursos incluidos en la propuesta.

LANDING PRINCIPAL

Captación de usuarios

Uno de los componentes principales del proyecto es el formulario de captación incorporado en la landing. El usuario puede ingresar su nombre, correo electrónico y nivel de experiencia.

La interacción permite registrar la información del usuario y continuar con el proceso de acceso al roadmap educativo.

Automatización

SPACE 360 incorpora automatización como parte de su arquitectura, utilizando n8n para conectar diferentes procesos y servicios.

Esta integración permite plantear flujos automatizados relacionados con la gestión de información, distribución de contenidos y comunicación entre diferentes herramientas.

Automatización con n8n

El proyecto incorpora flujos de automatización desarrollados con n8n para conectar diferentes procesos y servicios. Esta implementación permite visualizar cómo se estructura el flujo de trabajo y cómo se integran sus diferentes etapas.

FLUJO DE AUTOMATIZACIÓN

Integración con Google Cloud

El proyecto también incorpora servicios de Google Cloud como parte de su ecosistema tecnológico.

La utilización de servicios cloud permite conectar diferentes componentes y construir una infraestructura preparada para integraciones y automatizaciones.

APIs y OAuth2

La arquitectura contempla el uso de APIs para permitir la comunicación entre diferentes plataformas y servicios.

OAuth2 forma parte del sistema de autorización utilizado para establecer conexiones entre servicios que requieren autenticación y acceso controlado.

Contenido educativo

La landing presenta un roadmap estructurado en diferentes módulos para acompañar al usuario desde los conceptos iniciales hasta la creación de sus primeros proyectos.

Entre los contenidos se incluyen fundamentos de Cloud, Inteligencia Artificial, automatización, herramientas no-code, portfolio y conceptos fundamentales del entorno tecnológico.

CONTENIDO DE LA GUÍA

Herramientas y tecnologías

La propuesta integra diferentes herramientas utilizadas actualmente en desarrollo web, automatización, inteligencia artificial y servicios cloud.

Entre ellas se encuentran n8n, Google Cloud, APIs, OAuth2, JavaScript y tecnologías web como HTML y CSS.

Diseño y experiencia

La interfaz fue diseñada para presentar una gran cantidad de información de manera ordenada, utilizando secciones, tarjetas, indicadores, etiquetas y bloques de contenido.

La estructura busca facilitar la navegación y permitir que diferentes perfiles de usuarios puedan identificar rápidamente el contenido relevante para su nivel.

Arquitectura del proyecto

SPACE 360 combina una interfaz web estática con lógica desarrollada en JavaScript e integraciones externas mediante APIs y servicios cloud.

La incorporación de n8n permite ampliar el funcionamiento del proyecto mediante flujos automatizados, mientras que OAuth2 permite gestionar conexiones autorizadas con servicios externos.

Resultado

El resultado es un ecosistema educativo digital que combina desarrollo web, captación de usuarios, automatización, servicios cloud e integración mediante APIs.

El proyecto permite presentar una propuesta educativa completa y, al mismo tiempo, aplicar diferentes tecnologías en un caso práctico de desarrollo e integración.
